# Examples

This directory is reserved for example game definitions and playable adventures demonstrating supported runtime behavior. Examples should be genre-agnostic demonstrations where appropriate, use supported canonical formats and clearly identify required capabilities and engine compatibility.

The current canonical definition format is 3.0.0. Existing [test fixtures](../tests/README.md#foundation-fixtures) are specification and verification data, not playable examples. The versioned author guide is planned under [FND-11 (#20)](https://github.com/ja-sanborn/asterweave/issues/20).

Read the [documentation index](../docs/README.md), [canonical definitions](../docs/contracts/GAME_DEFINITIONS.md) and [roadmap](../docs/ROADMAP.md). Preserve applicable licenses and attribution; independently authored games may use separate licenses subject to MPL obligations for covered source. Do not commit private stories, local saves or generated distributions.

No playable example exists yet.
