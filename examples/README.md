# Examples

This directory is reserved for example game definitions and playable adventures demonstrating supported runtime behavior. Examples should be genre-agnostic demonstrations where appropriate, use supported canonical formats and clearly identify required capabilities and engine compatibility.

The current canonical definition format is 3.2.0. Existing [test fixtures](../tests/README.md#foundation-fixtures) are specification and verification data, not playable examples. A versioned author guide is planned.

Read the [documentation index](../docs/README.md), [canonical definitions](../docs/contracts/GAME_DEFINITIONS.md) and [roadmap](../docs/ROADMAP.md). Preserve applicable licenses and attribution; independently authored games may use separate licenses subject to MPL obligations for covered source. Do not commit private stories, local saves or generated distributions.

Lantern House is planned as a complete original example, playable through direct actions and the optional Text Parsing Extension. Zork I is a subsequent native reference recreation, not an emulator or core dependency; fidelity, licensing and redistribution rights require review. Keep game-specific behavior in authored data or optional extensions and track genuine general engine gaps separately. No playable example exists yet.
