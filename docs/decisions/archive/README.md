# Archived architecture decision records

These records (0001–0027) are retained for historical purposes only. They are not authoritative and are outside mandatory contributor reading. Consult the [active ADR index](../README.md), current architecture and normative contracts. Each archived record identifies its replacement active ADRs. Original decision text, including historical status and references, is preserved; historical relative references may reflect the original layout. The active series begins at 0051; identifiers 0028–0050 are intentionally unused.
