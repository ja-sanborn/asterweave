# Code of Conduct

Asterweave welcomes contributors of all backgrounds and experience levels. Treat others respectfully, offer constructive feedback, and focus disagreements on ideas and work rather than people.

Harassment, discrimination, threats, personal attacks, unwanted sexual attention, and publication of another person's private information without consent are unacceptable.

These expectations apply to repository discussions, issues, pull requests and other official project spaces. Maintainers may moderate content, restrict participation or report violations to GitHub as appropriate.

Report conduct concerns privately to a maintainer through an available private contact channel or use GitHub's reporting tools. Do not post sensitive personal information in public issues. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
